# Hostillam

Official website for **Hostillam** — hosting beautiful minds. A soulful homestay and camping experience in Kodaikanal.

## Stack

- React + Vite
- JavaScript
- Tailwind CSS

## Getting started

```bash
npm install
npm run dev
```

Production build:

```bash
npm run build
npm run preview
```

## Configuration

Update WhatsApp number, contact details, accommodations, prices, and social links in:

- `src/config/site.js`
- `src/data/content.js`

Booking enquiries open WhatsApp with a pre-filled message. There is no online payment or booking backend.
